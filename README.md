# GIRA · MVP V5

Prototipo interactivo mobile-first en HTML, CSS y JavaScript. Abrir `index.html` en el navegador. No requiere instalación ni compilación.

## Despliegue
Importar este repositorio en Netlify, rama `main`, sin comando de build, directorio de publicación `.`.

## Alcance
Simulación UX/UI; no procesa pagos ni pedidos reales, no conecta Firebase ni WhatsApp real. Los datos, precios y estados son de prueba.

Las iteraciones deben preservar los flujos existentes y quedar versionadas en Git.
